# My AI Personal Assistant
A simple python-based personal assistant project created by a first year btech cse student.

## Features 
-Greets the user by name
-Displays the current time
-Displays the current date
-Gives greetings based on the time of the day
-Performs basic calculations

## Technologies Used
-Python
-Datetime module

## How to run
1. Download 'main.py'.
2. Open it in a python editor.
3. Run the program.
4. Enter your name and follow the instructions.
